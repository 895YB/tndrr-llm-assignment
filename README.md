# Tndrr LLM R&D Assignment

This repository contains reproducible implementations for the three requested tasks: LoRA fine-tuning, a from-scratch RAG pipeline, and local quantization benchmarking.

> **Experiment status:** Code, test data, and evaluation harnesses are included. Hardware-dependent metrics (accuracy, Recall@5, tokens/sec, peak memory, and model output comparisons) must be generated by running the scripts. No benchmark values are fabricated.

## Layout
- `task-1-finetuning/` — Qwen2.5-0.5B-Instruct LoRA, 60 held-out examples, evaluation and 7B memory estimator.
- `task-2-rag/` — public-document loading, chunking, sentence-transformer embeddings, NumPy cosine search, 15 QA pairs, Recall@5 at two chunk sizes.
- `task-3-local-llm/` — same 10 prompts, FP16 vs 4-bit inference benchmark, throughput and GPU memory collection.
- `report/FINAL_REPORT.md` — report template for actual measured results.

## Setup
Python 3.10+ recommended. Use a Linux GPU / Colab runtime for Tasks 1 and 3.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

Run `python validate_project.py` for a no-GPU syntax / manifest / split check. See [COLAB_RUNBOOK.md](COLAB_RUNBOOK.md) for end-to-end execution on a Colab GPU. Follow each task README. Models and the public source document download on first run. Record GPU, driver, versions, precision, sequence length, batch size, and runtime.

## Reproducibility and integrity
The fine-tuning data uses a deterministic split. RAG questions include reference source text for retrieval evaluation. Scripts print/save actual metrics. Do not report placeholder values as experimental measurements. This repository supplies reproducible code; the final report must be completed after experiments on the target hardware.
